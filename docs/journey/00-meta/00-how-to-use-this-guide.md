# 00 How to use this guide

Goal / Non-goal / Where in code / Concept / Flow / Rewrite options / Exercise / Done when.

Goal: read one file per session, do the exercise in code. Non-goal: memorizing architecture.
Where in code: `docs/README.md`, `docs/journey/README.md`, `tasks.md`.
Concept (learning): active recall — after each file, close it and explain the flow aloud.
Flow: read -> exercise -> `go vet ./...` + `pnpm exec tsc --noEmit` -> 5-line log in `.dev-data/work/`.
Rewrite options: keep this loop, or shorten to 30 min; never skip the exercise.
Exercise: create `.dev-data/work/log.md` with date + one thing learned about Backend bridge.
Done when: you can state the 8-week calendar from memory.
