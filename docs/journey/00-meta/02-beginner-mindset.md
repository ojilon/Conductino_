# 02 Beginner mindset: redo, rethink, correct AI code

Goal / Non-goal / Where in code / Concept / Flow / Rewrite options / Exercise / Done when.

Goal: give yourself permission to delete AI decisions. Non-goal: blaming the AI.
Where in code: every `// NOTE`, `TODO`, mock fallback (e.g. `frontend/src/services/backend.ts:186 catch->null`).
Concept: code is a hypothesis. Your job: test it against your UX (different folders per topic, light machine).
Exercise: list 5 AI decisions you disagree with (e.g. React-heavy UI, flat documents map) in your log.
Done when: you have a personal 'redo list' of 10+ items.
