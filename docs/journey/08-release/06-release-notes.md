# 08-06 Release notes discipline

Goal / Non-goal / Where in code / Concept / Flow / Rewrite options / Exercise / Done when.

Goal: every tag has notes. Where: `release-prep/release-notes/TEMPLATE.md`, `v0.0.1.md`, `v0.0.2.md`.
Exercise: write notes for next tag (what changed, migrations, known issues).
Done when: notes written before tag, not after.
